# also refuses a `measured_bytes` that does not equal the artifact (`ACTUAL == MEASURED`),
# because a stale floor was previously invisible.

# Still blocked: the **default** flip. Not by size — 1337205 B fits — but by
# `check-bundle-independence.sh`: `rigorix-engine` declares `tokio` as a required dependency
# (`engine/Cargo.toml:49 tokio.workspace = true`) and `portable = []` does not remove it, so
# the engine-linked graph carries an async runtime into a single-threaded module. ADR-014's
# inventory excludes tokio-using *modules*; it never excluded the *crate* dependency, and this
# gate is the first thing to say so out loud. Follow-up is engine-side (make tokio optional /
# feature-gate it), with its own blast radius — it is not a bundle change.
#
# Lesson, verbatim, because it has now cost two verdicts: **the artifact is whatever the
# packaging path builds, and the packaging path must build the profile the budget assumes.**

# the root workspace, and lto/panic cannot be overridden per package — so the profile cannot
# live in a manifest where it would read as a decision and change nothing.
