# ── #1401: the default build is the one that decides ────────────────────────────────────
# ``default = ["engine"]``. Every number in this file before this section described a build a

# `gate_unavailable`, and reported `"gate_evaluation": false`. The gate was behind a flag.
#
#   command: bash wasm/ci/wasm-build.sh            (no feature flags — the default)
#            wasm-bindgen --target nodejs --out-dir wasm/pkg
#            python3 wasm/ci/strip_name_section.py .../rigorix_gate_wasm_bg.wasm
#   emitted 1769863 B · name section 432658 B · shipped 1337205 B
#   ceiling 1500000 B  →  10.9 % headroom   ·   budget (measured + 25 %) 1671506 B
#
# What unblocked it was not a byte. It was three statements being made true at once: `sync` is
# not a runtime (#1400); the independence gate asserts the feature-set property rather than
# banning a crate name the design legitimately uses; and this file's `measured_bytes` is now
# the artifact it claims to be. The budget moved 169250 → 1337205 for the only reason that
# justifies it: **the measured artifact changed**, from the unlinked build to the shipped one.
#
# The unlinked build still exists (`--no-default-features`), still compiles, still reports
# `gate_evaluation: false`, and still refuses at open. That is a dev configuration with an

# ── #1405: the measurement is a per-machine fact ────────────────────────────────────────
# `check-bundle-size.sh` refused an artifact whose recorded size did not match exactly. On the
# same commit, same pinned toolchain (1.96), same `wasm-bindgen` (0.2.130):
#
#   macOS            shipped 1337205 B
#   Linux CI runner  shipped 1335752 B   (-1453 B, -0.11 %)
#
# Neither is wrong. Panic messages and debug strings embed absolute paths, and the two hosts
# build from different ones. A byte-exact floor is therefore a claim about one machine, and
# asserting it in CI refused a correct artifact on every run — a gate that is always red hides
# the ones that are sometimes red.
#
# So the floor comparison carries a declared 1 % build-environment tolerance. The property
# #1386 added it for is intact: it caught the 169250 → 1337205 change (a 690 % delta) the
# moment the flip landed, and 1 % is two orders of magnitude below any change worth a
# re-record. `budget_bytes` and `ceiling_bytes` remain hard, exact comparisons.
#
# If byte-reproducibility across machines is ever wanted, the route is `--remap-path-prefix`
# in `ci/wasm-build.sh`: measured locally it removes 1344 of the 1453 B. It is not done here,
# because it changes the artifact — and a change to the artifact is what this file records,
# not something to slip in with a gate fix.

# ── Phase C.6 (#1386): the profile, not the code ─────────────────────────────────────────
# The 1 706 234 B below was correct and was not the number that matters: `wasm/Cargo.toml`
# declared no `[profile.release]`, so the artifact shipped with opt-level 3, no LTO and 16
# codegen units. `ci/wasm-build.sh` now owns the profile (fat LTO, opt-level z, panic=abort,
# codegen-units 1) and every build in `ci/` goes through it:
#
#   default release profile         emitted 1918610 · name 212376 · shipped 1706234  (+13.7 %)
#   size profile (#1386)            emitted 1769863 · name 432658 · shipped 1337205  (-10.9 %)
#
# `measured_bytes` described the artifact this gate measured at the time — the **default**
# build, which was then unlinked, hence 169250 B (down from 209881 B: C.3 deleted `SeamGate`
# and the probe). The engine-linked figure the flip decision rested on is 1337205 B; both were
# measured through this commit's packaging path, and the gate refuses a `measured_bytes` that
# does not equal the artifact it just measured. That is what caught the 169250 as stale the
# moment `default = ["engine"]` landed (#1401, above). `budget_bytes` is measured + 25 % (1671506),
# which is *above* the `ceiling_bytes` of 1500000 — so the ceiling binds, deliberately: the
# ratchet is derived and the ceiling was fixed by the specification. Both are asserted, and the size gate now
# also refuses a `measured_bytes` that does not equal the artifact (`ACTUAL == MEASURED`),
# because a stale floor was previously invisible.
#
# Then blocked: the **default** flip. Not by size — 1337205 B fits — but by
# `check-bundle-independence.sh`, which banned the *crate name* `tokio`: the engine-linked graph
# carries it, and `portable = []` does not remove a target-specific dependency. Two corrections
# came out of that, and both are the finding: the tokio that reached wasm32 was the
# target-specific declaration narrowed to `["sync"]` (#1402), and the rule that refused it was
# banning a name instead of asserting a property (#1401, top of this file). Neither was a bundle
# change, which is why both were filed instead of patched here.
#
# Lesson, verbatim, because it has now cost two verdicts: **the artifact is whatever the
# packaging path builds, and the packaging path must build the profile the budget assumes.**
# A `[profile.release]` in `wasm/Cargo.toml` would have been ignored — `wasm` is a member of
# the root workspace, and lto/panic cannot be overridden per package — so the profile cannot
# live in a manifest where it would read as a decision and change nothing.
