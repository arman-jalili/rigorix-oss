  intent: |
    The harness already refuses an unlabelled golden (`run-conformance.sh`), and the label vocabulary
    has `fixture` and `seeded`. What it has never had is a vector whose label is **true**: `gate:
    \"cli\"` would assert that the expected bytes came from the CLI at the same commit, and nothing
    checks that claim.

    This issue makes the label checkable and then flips it. The provenance field is the part that
    matters: a vector must name the command that produced its bytes, so a `cli` label is a claim with
    an artifact rather than a hope.
