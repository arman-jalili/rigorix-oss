# #1520 — the wasm ADR register's citations, and the guard that never read it

## What was measured, then fixed

Running the engine guard against the wasm register reported six findings; four were citations and
two labels. Fixed:

| file | finding | fix |
|---|---|---|
| `ADR-010-artifact-format.md:102` | `@canonical .pi/architecture/decisions/ADR-010-…` resolved from no root the guard knows | rewritten to `wasm/.pi/…`; **13** crate-relative `@canonical` markers in the register corrected the same way |
| `ADR-010-artifact-format.md:115` | `Engine ADR-016 (…)` — a bare number that set does not contain | cites `engine/.pi/architecture/decisions/ADR-016-audit-integrity-anchor.md` |
| `ADR-002-data-storage.md:92`, `ADR-005-authentication.md:90` | the same engine-register reference | same fix |
| `ADR-012-…:94` | `engine ADR-009 (error handling)` — a relative qualifier the guard cannot see | cites the engine file |
| `ADR-013-…:111` | `ADR-005 (key custody)` — the label names nothing in that ADR's subject | `ADR-005 (key ownership and capability-free surface)` |
| `ADR-001-…:107` | `ADR-005 (authority)` — same | `ADR-005 (authentication and authorization)` |

Result: **14/14** citations resolve in the wasm register; the engine register stays **65/65**.

## The guard now reads both

`validate-adr-references.sh` checks the engine register and `wasm/.pi/architecture/decisions/` in one
run. Each register gets its own labels file — an engine record must not license a wasm label — and a
generated empty one stands in when a register has none. `--adr-dir` still means exactly one (the
self-test depends on it), and the loop **preserves each register's exit code**: collapsing them to 1
made the malformed seed (`a recorded label with no reason is refused`) read as a violation, which the
self-test caught immediately.

`.pi/guard-subjects.tsv` declares the wasm register, so the path→subject map keeps `audit` fed for it
(the rule #1514 added), and the scope note in the guard's header replaces #1514's "not checked" with
what is now true.
