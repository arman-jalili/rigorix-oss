# #1514 (CI-3) — a document change did not reach the document guard

Branch `issue/1514`. The defect is the one this session already fixed once for `engine/.pi/**`
(#1498) and now for `docs/**`: the path→subject map narrowed a change away from the only job that
runs the guard whose subject it is.

## The measurement, reproduced

```
.github/ci-affected.tsv:   docs/**  →  docs
ci.yml `docs` job:         validate-canonical.sh, validate-architecture.sh,
                           validate-architecture-readiness.sh   (NOT validate-docs.sh)
.pi/guards.tsv:            validate-docs.sh → gating, run_here=yes
validate-guards.sh:        runs every run_here=yes guard — in the `audit` job
```

So a pull request rewriting `docs/spec/**` reported success without running the documentation
validator. Same run: `wasm/.pi/architecture/decisions/**` matched no row and fell to the default.

## Work

1. `docs/**` → `docs,audit`; `*.md`, `**/*.md` → `docs,audit`; new `**/.pi/**` → `audit` (every
   crate's guard tree, which `validate-script-drift.sh` reads); `.claude/**`/`.agents/**` → `audit`
   (prose a public guard reads — that is how this session's own PR body was caught).
2. The rows whose contents a `run_here=yes` guard reads gain `audit`, so the guards actually run on
   their subject. Stated cost: `Audit` is selected by more changes; a guard that does not run is not
   a gate.
3. **The class becomes checkable.** `.pi/guard-subjects.tsv` says what each of the sixteen guards
   reads; `check_affected_map.sh` rule 5 fails when a guard's subject does not reach `audit`, when a
   declared glob matches no tracked path, and when a guard that runs here declares nothing. Seeds
   S6 (a subject that reaches no audit) and S7 (an undeclared guard).
4. **The wasm register**: the engine guard does not read it, and running it there reports four
   unresolved citations. ADR numbering is tree-local, so resolving them is a judgement about another
   register — the scope is stated in the guard's header and the findings are tracked in #1520, rather
   than the row being written into `guard-subjects.tsv` as if the guard read it.

## Acceptance
