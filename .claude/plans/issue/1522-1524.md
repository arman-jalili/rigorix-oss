## #1522 — the tip is red, and the two gates disagreed

`cargo audit --deny warnings` (the policy `hardening.yml:270` enforces) failed on
`a3d3774e` with RUSTSEC-2026-0486: `rustix` 1.1.4, "unsound", fixed in 1.1.6. Measured:

```
cargo update --dry-run -p rustix@1.1.4 --precise 1.1.6   → v1.1.4 -> v1.1.6   (one line moves)
cargo audit --deny warnings        after the bump        → exit 0
```

The second half is the defect worth a check: `.pi/scripts/languages/rust/validate-security.sh`
turned the same finding into `warn`, so the local gate was **green on a tree the pipeline called
unsafe**. It now runs the pipeline's command, quotes the crate and the advisory id, and fails, with
the remedy in the message (bump the dependency, or record a suppression with an expiry —
`.cargo/audit.toml` is a decision, not a silence). Mirrored to all five crates; drift check clean.

**Parity proven both ways, not asserted:** with the lockfile pinned back to 1.1.4 the validator
exits **1** and prints `ID: RUSTSEC-2026-0486`; restored to 1.1.6 it exits 0.

## #1524 — `.sh` was the one category nobody classified

Governed files (`.md`, `.tsv`, `.yml`, `.yaml`) naming the private repository: 0. Tracked `.sh`
files naming it: `demo/anchor-e2e/run.sh`, twice — a `mktemp` prefix on `:48` while `:49` two lines
below already did it correctly, and the anchor binary's path on `:76`.

- `.sh` is governed now, and the scope note says why: a shell script is a runbook.
- The temp prefixes are neutral; the binary is configured — `ENT_BIN` if set, else the single
  executable under `core/target/debug`, with a named error if that is ambiguous — because its name
  belongs to a repository this tree may not name.
- The guard's own fixtures use an unregistered placeholder, never a real name. The guard
  does not read itself: a plant must stay unregistered, and a registered plant passes for the wrong
  reason. The exclusion is stated, and a seed asserts that a `.sh` file *is* governed so the
  exclusion cannot grow into the taxonomy.
- Four identifiers registered from `.sh` files (`rigorix-release-ci`, `rigorix-e2e-pg`,
  `rigorix-seed-post`, `rigorix-e2e-exports`).

Measured after: **0 tracked files name the private repository, in any extension.**
